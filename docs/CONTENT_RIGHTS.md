# 素材来源与使用依据

本网站为独立个人粉丝纪念项目，与张杰本人、其工作室、唱片公司及官方团队无隶属关系。第三方素材的权利归相应权利人所有。未经授权的素材不应通过本网站公开传播。

系统初始不预置商业歌曲、MV、歌词或虚构经历。所有者提供的演唱会海报和“小北斗”拼图（`original-poster.png`、`original-beidou.png`）仅用于确定配色，不在网页中展示；旧文件 `poster.jpg` 也不再作为页面素材或读取路由。首页展示另行提供的现场照片：主图保存在 `stage.jpg`，伴图保存在 `beidou.jpg`；原始照片 `original-stage.png` 和 `original-companion.png` 只留在本机私有主题目录，不由图片接口提供。蓝色双片衬线 V 参考图用于绘制站点标志。上述用户提供的素材与收藏媒体分开保存，仅在通过认证后读取，提供图片不构成公开传播许可。主图缺失时，首页会使用 `assets/licensed/` 中有明确来源和 CC BY-SA 4.0 许可的张杰照片。原创星轨背景由代码生成。自动生成的测试 PNG、WAV 与短视频为测试脚本生成的图形和音调，不作为正式收藏展示；生产模式回归若需使用所有者主题图，会将可服务的固定文件复制到隔离的 `.test-data/` 目录。

对每项素材记录来源 URL、权利人、许可类型、许可说明、署名要求和允许范围。`unknown` 表示未核实，`do_not_publish` 明确禁止公开，`personal_only` 仅记录个人使用依据，`licensed` 仍须核对许可具体范围及期限。公开网页可观看不等于允许下载、再上传或重新传播；非商业用途也不自动构成授权。

权限分开保存：文字来源记录、个人收藏、私人存储、私人站内播放、官方播放器嵌入、公开展示、仅跳转。当前版本始终私人，无公众内容发布入口；保存 `public_display` 元数据不会开放任何私人内容。未来若建设公开页面，应先建立独立发布读取模型、逐项审核许可和署名，禁止把日记、信件或私人附件随公开开关一并曝光。

优先添加正规音乐平台或官方观看入口。官方嵌入必须遵守平台规则，失败时使用原始观看链接，不绕过登录、地域或保护机制。不自动抓取或盗链，不提供批量下载、歌词复制或去广告功能。纪念册和星系导出也应根据将要分享的范围重新核实内容，主动选择条目后再导出。
