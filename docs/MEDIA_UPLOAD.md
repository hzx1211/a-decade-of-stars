# 媒体上传与播放

使用“添加记录”或“编辑”中的文件区域，选择文件后发起上传。权利人、来源和许可说明等字段只在信息已知时填写；系统不会替用户编造这些信息。文件默认保持私人，上传进度来自真实传输事件，只有服务端确认完成后才记为 100%。网络中断会提示服务端保存状态尚未确认；云端取消会请求清理未完成的临时对象，已保存的素材会保留。当前是单次上传，**不支持断点续传或后台转码**。

| 类型 | 默认应用上限 | 接受格式 |
| --- | --- | --- |
| 图片 | 10 MB | JPEG、PNG、WebP、GIF、AVIF |
| 音频 | 50 MB | MP3、WAV、OGG、FLAC、M4A/MP4 音频 |
| 视频 | 100 MB | MP4、WebM |

云端额外受 `CLOUD_UPLOAD_LIMIT_MB` 限制，默认 50 MB，配置必须大于 0 且不超过 50 MB。实际大小还受对应媒体类型上限、站点设置及 Supabase 套餐限制；这些限制取其中较小值。

本地模式中，浏览器把文件提交到认证的应用接口，由 Node 服务端校验并保存到私有数据目录。Supabase 模式中，浏览器先向认证的初始化接口发送小型 JSON 请求，取得短期签名上传地址后使用 PUT 将文件直接传到非公开 `private-media` Bucket，再调用认证的完成接口。服务端会校验对象大小、MIME 和文件内容签名，通过后才建立素材记录；完成接口异常时会重试确认，不会重复上传文件字节。应用 API 使用真实 XHR 上传进度，云端在确认完成前不会报告成功。

所有内容与媒体都必须由所有者认证后访问，包括记录带有历史 `isPublic=true` 标记的情况；匿名 GET/HEAD 请求仍返回 401。媒体的来源、权利人、许可状态和使用范围只记录已知事实。私人保存不代表取得了公开展示或播放授权；需要播放时，应确认相应使用依据。

本地媒体响应支持 Range / 206 以便播放器拖动，无效范围返回 416。云端媒体通过认证接口读取私有对象或生成短期 URL；不要改成 public Bucket 解决播放失败。

照片支持灯箱、方向键与 Esc。音频和视频使用原生 HTML5 控件，默认不自动有声播放；实际解码失败显示错误。容器通过检查不代表所有浏览器支持其编码；本版本不转码。官方嵌入只接受白名单 YouTube / 哔哩哔哩地址并设置 iframe 限制，嵌入需相应使用范围；其他平台只保存外部链接并明确跳转观看。遵守平台访问、广告和地区限制。

替换媒体先上传一个新 asset，再更新记录引用；不要覆写仍被其他记录使用的文件。删除有引用的 asset 会被拒绝，先移除封面、正文、首页等引用。上传成功但记录保存失败时，已上传素材可能留在私人媒体列表；核对引用后再删除。数据库备份不包含真实文件，详见 BACKUP_RESTORE.md。
