# 媒体上传与播放

使用“添加记录”或“编辑”中的文件区域。填写素材权利人、授权状态、使用依据和使用范围，选择文件后发起上传。进度来自真实 XMLHttpRequest 上传事件，完成必须收到服务端成功响应；取消、错误与重试不伪造成功。大文件通过浏览器上传流，不将整段视频读入浏览器内存。当前首版是单次上传，**不支持断点续传或后台转码**。

| 类型 | 默认应用上限 | 接受格式 |
| --- | --- | --- |
| 图片 | 10 MB | JPEG、PNG、WebP、GIF、AVIF |
| 音频 | 50 MB | MP3、WAV、OGG、FLAC、M4A/MP4 音频 |
| 视频 | 100 MB | MP4、WebM |

服务端同时验证身份、大小、扩展名、MIME、文件头签名、路径及使用依据。浏览器直接发送 File；服务端对单次 multipart 做强制限额下的内存解析，当前不是 TUS 或端到端流式入库。实际允许大小取环境变量上限和站点设置较小值。Supabase Bucket 和托管平台另有限制，尤其 serverless 请求体限制可能先于应用生效；超出时应使用受控自托管、降低文件大小或另行建设经授权的分片上传通道，不能声称当前方案适合任意长视频。

上传需要 `personal_only` 或 `licensed`、非空权利人和许可说明，以及 `private_storage`。站内音视频播放需要 `private_playback`。未知授权可保存文字元数据或正规平台链接，不上传原始文件。勾选范围只是记录依据，不能创造许可。

本地二进制保存在非公开数据目录，响应只有经验证的所有者可访问，支持 Range / 206 以便播放器拖动。无效范围返回 416。云端私有 Storage 提供受认证访问或短期 URL；不可改为 public Bucket 解决播放失败。

照片支持灯箱、方向键与 Esc。音频和视频使用原生 HTML5 控件，默认不自动有声播放；实际解码失败显示错误。容器通过检查不代表所有浏览器支持其编码；本版本不转码。官方嵌入只接受白名单 YouTube / 哔哩哔哩地址并设置 iframe 限制，嵌入需相应使用范围；其他平台只保存外部链接并明确跳转观看。遵守平台访问、广告和地区限制。

替换媒体先上传一个新 asset，再更新记录引用；不要覆写仍被其他记录使用的文件。删除有引用的 asset 会被拒绝，先移除封面、正文、首页等引用。上传成功但记录保存失败时，已上传素材可能留在私人媒体列表；核对引用后再删除。数据库备份不包含真实文件，详见 BACKUP_RESTORE.md。
